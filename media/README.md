# Media

A short promo for Chromavision: the TV row on the Chromatic start-up menu, with the custom retro Local
Weather channel and optional Live TV from your own Jellyfin server.

| File | What it is |
|---|---|
| `chromavision-1080x1080.mp4` | Promo, square (20 s) |
| `chromavision-1920x1080.mp4` | Promo, wide (20 s) |
| `chromavision-still-1600x900.png` | Still picture |

All videos are MP4 (H.264, 30 fps, AAC sound). Stream quality on the console may vary.
